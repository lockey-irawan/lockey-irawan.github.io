Even Semester 2025/2026

Data Structures

This course provides a comprehensive foundation in data structures and algorithms using the Java programming language. Starting with essential Object-Oriented concepts, students will master efficient data organization techniques. The curriculum explores dynamic linear structures—such as Singly and Doubly Linked Lists, Stacks, and Queues—before advancing to non-linear systems like Binary Trees and Graphs. Through practical coding and a final project, students will learn to implement and manipulate these structures to solve complex computational problems.
