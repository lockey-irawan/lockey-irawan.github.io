Database Design

This course provides a comprehensive exploration of database systems, progressing from conceptual design to practical implementation using Oracle technologies. Students will master data modeling techniques, including Entity Relationship Diagrams (ERDs) and normalization, before transitioning to relational database management with Oracle Application Express (APEX). The curriculum covers essential SQL skills, ranging from basic data retrieval and sorting to advanced table joins, aggregate functions, and set operations. Finally, students will learn to ensure data integrity and optimize access through the implementation of constraints and database views.

Fundamentals of Database Modeling
This session introduces the core principles of database design, distinguishing between conceptual and physical data models. Students will learn to identify key database components—including instances, entities, attributes, and identifiers—and apply these concepts to construct basic Entity Relationship Diagrams (ERDs) representing real-world data structures. This week deepens the understanding of data associations by focusing on identifying relationships and mastering standard ER diagramming conventions. Complex Relationships and Data Operations
This session addresses the nuances of data connectivity, including relationship transferability and classifying relationship types. Students will learn the critical technique of resolving many-to-many relationships into associative entities and analyze CRUD (Create, Read, Update, Delete) requirements to ensure the data model supports necessary business operations. 		Download Module 3

This week focuses on temporal aspects of database design, specifically techniques for modeling historical data and tracking changes in time or price over time. Relational Concepts and Mapping Transformation
Bridging the gap between design and implementation, this session introduces fundamental relational database concepts. Students will master the transformation process by learning how to map conceptual ER models, relationships, and subtypes into physical relational table structures (schemas). 		Download Module 5

Logic, Sorting, and Single-Row Functions
This session advances SQL querying skills by exploring logical comparisons and understanding operator precedence rules. Students will learn methods for sorting retrieved data rows and get an introduction to using database functions to manipulate data items. 		Download Module 7

Advanced Data Retrieval with Joins
This week focuses on querying data from multiple tables simultaneously using various Join techniques. Topics include Cross, Natural, Inner, and Outer Joins, as well as Self-Joins for recursive relationships and Hierarchical Queries to navigate tree-structured data within tables. 		Download Module 8
#11 - 12
Aggregate Functions and Null Handling
These sessions concentrate on multi-row processing using Group Functions to aggregate data. Students will master specific functions like COUNT and DISTINCT for statistical summaries and learn essential techniques for handling null values using functions like NVL to ensure data accuracy in reports. Students will explore advanced analytical operations like ROLLUP, CUBE, and GROUPING SETS for multi-dimensional analysis, as well as Set Operators (such as UNION and INTERSECT) to combine results from multiple queries.
