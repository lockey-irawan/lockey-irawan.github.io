Extended Reality Design

This course is designed to provide a fundamental understanding of the Python programming language. Students will learn basic syntax, data structures (lists, dictionaries), functions, string manipulation, and an introduction to libraries for simple data analysis such as Pandas and NumPy. The learning focus is on writing clean and efficient code.

Session / Week Topic Discussion Action / Module

Introduction to Extended Reality Design
This topic provides a comprehensive overview of the Extended Reality (XR) spectrum, exploring the fundamental differences between AR, VR, and MR, and their transformative impact on modern industrial and educational landscapes. 		Download Module 1

Foundations of AR Technology
This topic explores the technical pillars of Augmented Reality, focusing on how computer vision, sensor fusion, and spatial tracking algorithms work together to align digital content with the physical world. 		Download Module 2

Unity Engine for AR Setup
This topic covers the essential configuration of the Unity development environment, including SDK integration and project optimization for deploying stable Augmented Reality applications on mobile platforms. 		Download Module 3
#4
Marker-based AR (2D & 3D Tracking)
This topic explores the implementation of marker-based tracking, focusing on creating and managing image and cylinder databases to trigger precise 3D content overlays in physical environments. 		Download Module 4
#5
Markerless AR (Ground Plane)
This topic introduces SLAM-based tracking through the Ground Plane feature, enabling students to detect physical surfaces and anchor digital objects in real-world spaces without the need for visual markers. 		Download Module 5
#6
Interactive AR: Virtual Buttons
This topic demonstrates how to create physical-to-digital interactions by implementing virtual buttons on markers, allowing users to trigger digital events through physical occlusion. 		Download Module 6
#7
UI/UX Design for AR Mobile
This topic examines human-centric design principles for spatial interfaces, focusing on creating intuitive mobile AR layouts that prioritize user ergonomics and visual clarity. 		Download Module 7
