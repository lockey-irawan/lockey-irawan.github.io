Advanced Database

This course provides an advanced exploration of PL/SQL (Procedural Language/SQL) within the Oracle database environment, bridging the gap between standard query operations and complex application logic. Students will progress from foundational procedural structures—such as variables, control flow, and cursor management—to sophisticated modular programming techniques.

Learning Timeline (16 Sessions)

Session / Week Topic Discussion Action / Module
#1
Introduction to PL/SQL
This module introduces PL/SQL as a high-performance, transaction-processing extension to standard SQL. We will explore its block-structured architecture, emphasizing how it reduces network traffic and enhances security by allowing procedural logic to reside directly within the database engine. 		Download Module 1
#2
Variables & Data Types
Effective memory management begins with the precise declaration of data structures. This session examines the scope, visibility, and memory allocation of scalar and non-scalar variables, ensuring data integrity through the strict enforcement of Oracle’s data type hierarchy. 		Download Module 2
#3
Manipulating Data in PL/SQL
We transition from static queries to dynamic Data Manipulation Language (DML) within procedural blocks. The focus is on the seamless integration of SQL commands and PL/SQL variables, maintaining transactional atomicity and consistency during complex data operations. 		Download Module 3
#4 - 5
Conditional Control & Iterative Control
These lectures dissect the flow-control mechanisms essential for complex business logic. We will analyze the computational efficiency of various branching structures (IF-THEN-ELSE, CASE) and loop iterations (FOR, WHILE), prioritizing code readability and execution performance. 		Download Module 4
#6
Cursors
To manage multi-row result sets, we implement Cursors as mechanism-controlled work areas. We will evaluate the technical trade-offs between implicit and explicit cursors, focusing on attribute management and resource deallocation to prevent memory leaks. 		Download Module 5
#7
Composite Data Types & Exception Handling
This session covers two pillars of robust programming: the use of Records and Collections to handle grouped data as a single unit, and the implementation of a centralized Exception Handling framework to ensure graceful degradation and professional error logging during runtime anomalies. 		Download Module 6
#8
Midterm Exam (UTS)
Evaluation of material from sessions 1 to 7. Format: Live Coding / Mini Project. 		Mandatory Attendance
#9
Procedures
We initiate the study of modular programming by designing Stored Procedures. The discussion centers on the abstraction of business rules, the use of IN/OUT parameters, and the security benefits of executing compiled code with specific privileges. 		Download Module 7
#10 - 11
Functions
Unlike procedures, Functions are designed for computational purity and value return. We will explore their role in expressions, the requirements for purity levels (WNDS, RNDS), and how they extend the native capabilities of the SQL language itself. 		Download Module 8
#12
Managing Packages
Packages represent the pinnacle of encapsulation in PL/SQL. We will discuss the architectural advantages of separating the 'Specification' from the 'Body,' enabling information hiding, persistent state management, and improved session-level performance through collective loading. 		Download Module 9
#13
Improving PL/SQL Performance
This module focuses on the 'Bulk Collection' and 'FORALL' features to minimize context switching between the PL/SQL and SQL engines. We will analyze execution plans and compiler hints to transform functional code into high-performance database assets. 		Download Module 10
#14 - 15
Recognizing and Managing Dependencies
The final sessions address the complexities of a live schema environment. We will examine how the database tracks object dependencies and the impact of 'invalidating' downstream objects. Students will learn to manage re-compilation strategies to maintain system availability during structural evolutions.". 		Download Module 11
#16
Final Exam (UAS)
Evaluation of material from sessions 9 to 15. Schedule according to university regulations. 		Final Project / Exam
