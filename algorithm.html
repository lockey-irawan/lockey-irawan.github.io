Algoritm & Programming + Laboratory

The Algorithms and Programming course provides a comprehensive exploration of fundamental computational logic and structured programming methodologies. The curriculum encompasses essential topics including algorithm design notation such as flowcharts and pseudocode, as well as core programming elements like data types, variables, and operators. As the course progresses, students delve into control structures, including conditional branching and iterative loops, to manage program execution flow. Furthermore, the syllabus covers advanced data structures such as single and multidimensional arrays, emphasizing the utilization of the NumPy library for matrix operations. Modular programming is introduced through the implementation of functions, alongside comprehensive string manipulation techniques. The course culminates in the application of standard searching and sorting algorithms, evaluated through theoretical and practical complexity analysis. By integrating theoretical discussions with hands-on laboratory practice, this course ensures students acquire the practical competencies required to design, simulate, and optimize technological applications.
