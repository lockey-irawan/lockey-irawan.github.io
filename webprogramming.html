Web Programming

This course offers a comprehensive guide to full-stack web development, bridging the gap between front-end design and back-end logic. Starting with the fundamental building blocks of the web (HTML & CSS) and responsive design using the Bootstrap framework, students will learn to create visually engaging and mobile-friendly interfaces. The curriculum then advances to client-side interactivity with JavaScript before diving into server-side programming using PHP and MySQL database management. The course culminates in a final project presentation where students demonstrate a fully functional, dynamic web application they have built.
